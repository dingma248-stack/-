# 雾港·长夜 — Mistport: The Long Night

一款在浏览器里运行的 **3D 第一人称生化恐怖射击游戏**。复古低像素画风、单人剧情、约 30 分钟通关。

> 22:40，雾港市。前刑警陈屿在商场值夜班时，监控画面里出现了异常。
> 05:00，军方将对整座城市执行「净化」。在那之前，他必须活着离开。

所有模型、贴图、音效和配乐都在浏览器里**程序化生成**——仓库里没有任何外部美术或音频文件。

---

## 快速开始

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览构建结果
```

需要支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox 最新版）。建议佩戴耳机——3D 音效使用 HRTF 空间化。

**提示**：进入游戏后点击画面锁定鼠标；觉得太暗可在 **设置 → 画面 → 亮度** 中调节。

**部署**：推送到 `main` 分支后，`.github/workflows/deploy.yml` 会自动构建并发布到 GitHub Pages（需在仓库 Settings → Pages 中把 Source 设为 *GitHub Actions*）。

## 技术与实现要点

**技术栈**：TypeScript（strict）· Vite · Three.js · Rapier（`@dimforge/rapier3d-compat`）· Web Audio API · `@fontsource`（Noto Serif SC / Cormorant Garamond / JetBrains Mono，本地打包）。

### 渲染（`src/render/`）
- 场景渲染到 **480×270**（可选 360p / 540p）的低分辨率目标，再最近邻放大；UI 保持高清。
- 材质顶点着色器统一打补丁实现 **PS1 顶点抖动**，强度可调。
- 后处理（单 Pass，低分辨率空间）：调色、单 Pass 光晕、色差、暗角、受伤红边、低血量降饱和、胶片颗粒、**Bayer 4×4 有序抖动 + 色深量化**；可选 CRT（扫描线 + 桶形畸变）。
- **光源池**：关卡可以声明任意数量的灯（闪烁灯管、警灯、火光、频闪、呼吸灯……），每帧把固定数量的 PointLight 分配给最相关的光源——Shader 光源数恒定，不会触发重编译。
- 手电筒是带阴影和 Cookie 贴图的 SpotLight，跟随相机但有轻微延迟摆动；电量有限。
- 程序化贴图：Canvas 绘制的 64/128px 贴图（瓷砖、水泥、柏油、砖墙、锈迹、木纹、血迹……），全部 `NearestFilter`。

### 关卡（`src/levels/`）
- 关卡用 **ASCII 网格（1 格 = 1 米）+ TS 脚本**描述。构建器自动生成合并后的地面 / 墙 / 天花板几何（带烘焙的伪 AO 顶点色）、贪心合并的 Rapier 碰撞盒、导航网格；支持高度差（楼梯、站台、轨道坑）。
- 静态道具按材质合批以减少 Draw Call。
- 剧情脚本是 `async` 函数（`wait` / `until` / `say` / `cutscene` / `camTo`），切关时自动作废。

### 物理与战斗（`src/physics/`、`src/weapons/`、`src/enemies/`）
- 玩家使用 Rapier `KinematicCharacterController`：上下楼梯、斜坡、贴地、滑墙；约 0.08 s 的加减速过渡；**土狼时间**与**跳跃缓冲**；体力、喘息声、落地下沉回弹、冲刺 FOV +5°。
- 每把枪：镜头后坐 + 自动回正、模型后坐动画、枪口火光（照亮周围一帧）、物理弹壳（会弹跳并发声）、弹孔贴花 / 火花 / 溅血；战术换弹与空仓换弹；霰弹枪逐发装填可随时打断；收枪 / 出枪动画。
- 敌人用分段骨骼的程序化模型，**命中部位局部弹簧受击**；死亡切换为**关节约束的布娃娃**；爆头打碎头部。
- 可破坏木箱 / 玻璃 / 酒瓶（刚体碎片）、可推动的椅子推车、径向爆炸冲击、弹簧铰链门（守夜人会把门整扇撞飞）、可撞破的墙。
- AI：网格 A* 寻路 + 直线平滑；**听觉**（枪声、冲刺、玻璃碎裂产生不同半径的噪音事件）与**视觉**（视锥 + 射线遮挡，手电与蹲伏会影响发现距离）。
- **导演系统**：根据紧张度切换动态音乐层、安排远处的环境音、在雾的边缘制造「看到但不确定」的人影；在医院（形态一）和研究所（形态二）控制守夜人的**随机闯入**——先是电台杂音和越来越近的脚步声，然后它从视线之外出现，追猎一段时间后撤走（躲进安全屋也会让它离开），每章至多一次。

### 音频（`src/audio/`）
- 所有音效在启动时离线合成到 AudioBuffer（噪声 + 滤波 + 包络 + 共振器）：每把枪不同的枪声、弹壳、换弹机械声、五种地面材质的脚步、感染者 / 犬 / 壁行者 / 守夜人的声音、门、玻璃、雨、风、警报、惊吓 Stinger……
- 3D 音效：`PannerNode`（HRTF）+ 距离衰减 + **墙体遮挡低通**；卷积混响按场景切换（房间、走廊、大厅、下水道、户外）。
- **动态配乐**：环境、紧张、战斗、守夜人主题、安全屋、标题主题六层，由实时音序器生成并交叉淡化。
- 音量分组：主音量 / 音乐 / 音效 / 语音与界面。

### 存档
安全屋的旧收音机可手动存档，进入新区域自动检查点。存档写入 `localStorage`（读写均包 `try/catch`，读不到就从头开始）。

## 调试

在 URL 后加 `?debug`，或游戏中按 <kbd>`</kbd>，打开调试面板：FPS、玩家坐标、最近敌人的 AI 状态、导演紧张度，以及「无敌 / 无限弹药 / 全武器 / 清敌 / 下一章 / 回血」按钮。

所有手感参数（移速、伤害、后坐力、敌人属性、难度倍率、画质档位）集中在 `src/config.ts`。

## 外部资源（可选）

`public/assets/` 预留给以后替换的 CC0 资源：放入 `public/assets/manifest.json` 即可按 key 覆盖程序化音效或贴图，**不需要改游戏逻辑**（见 `src/core/assets.ts`）。

## 已知问题与取舍

- 关卡是单层高度场：同一平面坐标上不能叠放两层可行走空间（楼上楼下通过把区域在地图上错开实现）。
- 林薇是脚本驱动的同伴：会跟随玩家，但不参与战斗，敌人也不会以她为目标。
- 画质档位中的光源数量和阴影开关在**下一次加载关卡**时完全生效。
- 在纯软件渲染（无 GPU）环境下帧率会很低；目标平台是带独显的台式机。
